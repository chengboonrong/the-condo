# GitHub Game Off 2026: rules (fetched 2026-11-05)

2026 rules are published, so no fallback to 2025 was needed. Sources, all fetched directly:

- A. GitHub blog, "Game Off 2026: The theme is SHIFT" (Lee Reilly, 2026-11-01): https://github.blog/open-source/gaming/game-off-2026-the-theme-is-shift/
- B. itch.io jam page: https://itch.io/jam/game-off-2026
- `https://gameoff.github.com` (the official short URL) 301-redirects to B. There is no separate GitHub-hosted rules page. `https://itch.io/jam/game-off-2026/rules` returns 404.

## 1. Third-party / pre-made assets

> "Use any tools and assets you prefer. Open source, commercial, commissioned, and original assets are all welcome." (A, "Light rules")

- No licence requirement for assets: any licence class is welcome.
- Credit: neither A nor B says anything about crediting assets, or where. Not confirmed either way. Crediting is therefore a courtesy and a licence matter (CC-BY etc. need it by their own terms), not a jam rule.
- The page does not name 3D models, textures, sounds or fonts. "Assets" is the only word used.

## 2. Public GitHub repository

> "Create a public repository. Store your game's source code on GitHub. Push your game before December 1, 2026, at 13:37 PST." (A, "How to participate")

> "Create a public repository. Store your source code on GitHub—open-source magic at its finest. Push your game before December 1 at 13:37 PST." (B)

> "Your game must live in a GitHub repository. You should begin the project during the jam, although templates and starter projects are welcome. The vast majority of the work should take place during the Game Off submission period." (A, "Light rules")

> "License it however you like. Open source is encouraged but not required." (A)

- Public repo required; code must be pushed by the deadline (not "made public after"). The text says "push", and the repo is called "public" in the same step.
- Pushing does not enter you: "Pushing your code to GitHub does not submit your entry to the jam." The itch.io submission is separate (A).
- Not stated: whether the repo is checked for being public at submission, or what happens if it is private. Not confirmed.

## 3. AI

> "AI-assisted development is allowed. We recognize that AI use in game development is a sensitive subject, and participants have different perspectives. When submitting your game, you'll be asked about your use of AI so others can better understand how it was made." (A, "Light rules")

- Allowed, no ban or cap. A disclosure question is asked at itch.io submission time.
- The text says "AI-assisted development" only. It does not separately mention AI-generated art, audio or text. Not confirmed beyond that line. B does not mention AI at all.

## 4. Deadline, timezone, theme

> "You have until December 1, 2026, at 13:37 PST to build and submit a game inspired by SHIFT." (A)

> "Submit your game on itch.io before December 1, 2026, at 13:37 PST." (A)

> "Voting will end on January 1, 2027, at 13:37 PST." (A and B)

- Deadline: 2026-12-01 13:37 PST (UTC-8), which is 2026-12-01 21:37 UTC. B's raw data agrees: `"end_date":"2026-12-01 21:37:00"`, `"start_date":"2026-11-01 21:37:27"`, `"voting_end_date":"2027-01-01 21:37:00"`. B's countdown shows 21:37 with no zone label; that is the UTC form of the same instant.
- Theme (announced 2026-11-01): "The theme for Game Off 2026 is SHIFT!" Interpretation is open: "How you interpret the theme is entirely up to you." and "Strong or loose inspirations apply!" (A)
- Judging categories: Overall, Gameplay, Graphics, Audio, Innovation, Theme Interpretation.

## Not confirmed (nowhere in A or B)

- Any asset credit or attribution rule or location.
- A named rule for fonts, textures, models or sounds, beyond the single "assets" sentence.
- A rule on AI-generated assets (as opposed to AI-assisted development).
- How "begin the project during the jam" is enforced for work started before 2026-11-01.
