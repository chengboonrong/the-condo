# The Condo: 11:47 PM

First-person psychological horror, made in Godot 4.7 for **GitHub Game Off 2026** (theme: **SHIFT**).

You've just come home from your shift at the mamak on the corner. At 11:47 PM the intercom rings: the neighbour downstairs
wants you to stop knocking. You live alone, and you haven't made a sound. Then three knocks come
from the bedroom wall, and the condo starts to shift whenever you aren't looking.

An adaptive Horror Director watches how you play (which rooms you avoid, how often you look behind
you, whether you chase sounds or hide in the light) and picks what happens next.

> Status: early prototype. See [docs/roadmap.md](docs/roadmap.md).

## Run it

Requires **Godot 4.7.2** (standard build, not .NET).

```sh
godot --path .                 # play
godot --path . --editor        # open in the editor
```

## Controls

| Action | Keys |
|---|---|
| Move | W A S D / arrow keys |
| Sprint | Shift |
| Crouch (hold) | C |
| Interact | E or left mouse |
| Phone light | F or right mouse |
| Pause / settings | Esc |
| Debug overlay (debug builds) | F3 |
| Fire knock / flicker / door / footsteps / silhouette (debug builds) | F5 – F9 |
| Next act (debug builds) | F10 |

## Tests

```sh
GODOT=/path/to/Godot tools/test.sh          # all tests, exit code 0 on success
GODOT=/path/to/Godot tools/test.sh --filter=room_graph
```

See [docs/test-plan.md](docs/test-plan.md).

## Project layout

| Path | Contents |
|---|---|
| `scripts/core/` | EventBus, WorldState, Settings (autoloads) |
| `scripts/world/` | Apartment layout data, room graph, builder, doors, interactables |
| `scripts/player/` | First-person controller and interaction |
| `scripts/horror/` | Events, scheduler, director, behaviour profiler, entity, room transformer |
| `scripts/story/` | Story director: acts, objectives, dialogue, fail-safes, endings |
| `resources/horror_events/` | Tunable event definitions (`.tres`) |
| `assets/audio/` | Sounds generated by `tools/gen_audio.py` |
| `tests/` | Headless test runner, unit and integration tests; `tests/sim/` holds the playthrough bots |
| `docs/` | Architecture, roadmap, event catalogue, test plan |

## Tools

* `tools/screenshots.gd` renders a contact sheet of every room (needs a window):
  `godot --path . --script res://tools/screenshots.gd -- --out=/tmp/condo_sheet.png`
* `tools/playthroughs.gd` rewrites [docs/playthroughs.md](docs/playthroughs.md), the record of three
  simulated players (bots, not people): `godot --headless --path . --script res://tools/playthroughs.gd`
* `tools/setup_input_map.gd` rewrites the input actions in `project.godot`.
* `tools/gen_audio.py` regenerates every sound (Python 3, standard library only).
