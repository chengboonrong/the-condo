# 11:47PM

First-person psychological horror, made in Godot 4.7 for **GitHub Game Off 2026** (theme: **SHIFT**).

> **Content warning:** blood and gore, a figure that appears suddenly, sudden loud sounds and flickering lights. The
> horror comes from Malay folklore. Not for young players.

The game starts on a foggy mountain road at midnight. The last staff bus has gone, and a couple stop to give you a
lift down. The road has rules, and something follows the car. At the bottom you wake up at home, and the clock says
11:47 PM.

You've just come home from your shift at the mamak stall up at the resort. At 11:47 PM the intercom rings: the neighbour downstairs
wants you to stop knocking. You live alone, and you haven't made a sound. Then three knocks come
from the bedroom wall, and the condo starts to shift whenever you aren't looking.

An adaptive Horror Director watches how you play (which rooms you avoid, how often you look behind
you, whether you chase sounds or hide in the light) and picks what happens next.

> Status: playable from the road to either ending of the flat, being polished for the jam. See [docs/roadmap.md](docs/roadmap.md).

## Run it

Requires **Godot 4.7.2** (standard build, not .NET).

```sh
godot --path .                 # play
godot --path . --editor        # open in the editor
```

| Debug overlay (debug builds) | F3 |

## Builds

```sh
GODOT=/path/to/Godot tools/export.sh   # web, macOS, Windows, Linux into builds/ (git-ignored)
tools/smoke.sh                         # checks index.pck against the 9936 KiB cap (exit 1 above it), then runs the macOS app and the web build (Chromium, WebKit) for 3 s each
```

The web build has no threads, so it runs on itch.io without special headers. The macOS app is signed
ad hoc, not notarised: on first launch macOS blocks it; open System Settings › Privacy & Security and
click Open Anyway (on macOS 14 and earlier, right-click the app and choose Open). Windows and Linux builds are
exported but have not been run yet. Performance results and how to measure them: [docs/performance.md](docs/performance.md).

## Project layout

| Path | Contents |
|---|---|
| `scripts/core/` | EventBus, WorldState, Settings (autoloads) |
| `scripts/world/` | Apartment layout data, room graph, builder, decor (furniture, trim, fixtures), doors, interactables |
| `scripts/player/` | First-person controller and interaction |
| `scripts/horror/` | Events, scheduler, director, behaviour profiler, entity, room transformer |
| `scripts/story/` | Story director: acts, objectives, dialogue, fail-safes, endings |
| `scripts/road/` | The road down the mountain: its core (`RoadDirector` and five missions), the road, the car, the couple, what follows them and the endings |
| `resources/horror_events/` | Tunable event definitions (`.tres`) |
| `assets/audio/` | Sounds generated by `tools/gen_audio.py` (five of them from the recordings in `art/sounds/vendor/`) |
| `assets/voice/` | The spoken lines, one MP3 each; `scripts/ui/voices.gd` maps each line's text to its file (see Licence) |
| `assets/models/` | The exported `.glb` models and their textures |
| `art/` | Blender build scripts and `.blend` sources for the models, and the recordings five sounds are cut from; not exported |
| `tests/` | Headless test runner, unit and integration tests; `tests/sim/` holds the playthrough bots |
| `docs/` | Architecture, roadmap, event catalogue, test plan, performance |

## Tools

* `tools/screenshots.gd` renders a contact sheet of every room (needs a window):
  `godot --path . --script res://tools/screenshots.gd -- --out=/tmp/condo_sheet.png`
* `tools/playthroughs.gd` rewrites [docs/playthroughs.md](docs/playthroughs.md), the record of three
  simulated players (bots, not people): `godot --headless --path . --script res://tools/playthroughs.gd`
* `tools/setup_input_map.gd` rewrites the input actions in `project.godot`.
* `tools/itch.sh` renders the itch.io page's cover and screenshots into `builds/itch/` (needs a window);
  the page text is in [docs/itch-page.md](docs/itch-page.md).
* `tools/gen_audio.py` regenerates every sound (Python 3, standard library only): it synthesises all but five, which
  it cuts from the recordings in `art/sounds/vendor/`.
* `tools/models.sh [id ...]` builds the models in Blender (every `art/<id>/build.py` when no id is given; they
  were built with 5.2.3) and imports them into the project. `BLENDER` (default: the macOS app's binary) and `GODOT`
  (default: `godot` on the PATH) come from the environment.
* `tools/road_stills.sh <dir>` renders stills of the road, one PNG per shot and a contact sheet (needs a window).
* `tools/stills.gd` renders the trailer-object stills and a contact sheet, `sheet.png`, beside them (needs a window):
  `godot --path . --script res://tools/stills.gd -- [--out=<dir>] [--before=<dir>]`. `--out` defaults to
  `/tmp/condo-stills/after`; with `--before`, each cell of the sheet pairs the still of that name from `<dir>` (left)
  with the new one.
* `tools/export.sh`, `tools/smoke.sh`, `tools/web_smoke.mjs`: builds and their checks (see Builds).
